This project presents the design and development of S.C.O.U.T. (Spatial Calculation & Obstacle Understanding Terrain-vehicle), a 4-wheel-drive autonomous obstacle-avoidance robot. The primary objective is to build a reactive, intelligent navigation system capable of safely traversing unknown environments without human intervention. The system utilizes an Arduino Uno microcontroller coupled with an L298N motor driver for mobility. For spatial awareness, we mounted an HC-SR04 Ultrasonic Sensor on a 180-degree servo motor.
Crucially, the system uses high-frequency sound waves (ultrasonic echolocation) instead of optical infrared sensors, ensuring reliable operation regardless of ambient lighting conditions like bright sunlight. The robot's algorithm continuously measures forward distance; upon detecting a barrier within 50 cm, it halts, reverses, and sweeps its sensor left and right. It then mathematically compares these distances to determine the optimal escape route. Experimental results over 100 trials demonstrated a 95% detection success rate and 88% turn accuracy, proving the system is a highly robust foundational platform for autonomous driving studies.
